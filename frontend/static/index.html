開始前，先了解系統存取限制

只有在你選擇網路並按下「產生分享 QR Code」後，系統才會讀取該網路所需的憑證。QR Code 在本機產生，不會送到 Help Agent 或雲端；任何掃描到 QR Code 的人都可能連線，請只分享給你選擇的對象。

即將產生包含 Wi-Fi 密碼的 QR Code

繼續後，系統會嘗試讀取你選定網路的憑證，並在這台裝置上產生 QR Code。密碼會包含在 QR Code 圖片中，不會傳送到雲端。

任何能看見、掃描或取得這張 QR Code 圖片的人，都可能連上這個 Wi-Fi。請只交給你信任的對象，並避免將圖片公開張貼。

使用說明

只協助操作本機分享介面；Help 不會連接本機 Wi-Fi API。請勿在對話貼入密碼。

💡
先在主畫面選擇網路，再按「產生分享 QR Code」。如果找不到網路或系統不允許分享，可查看使用說明；本機分享流程不會自動把密碼傳入 Help，請不要自行貼上。
